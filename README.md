# Retail Sales & Customer Analytics

## Project Overview

This project analyzes retail sales, customer, and product data to identify revenue trends, customer behavior, and product performance.

The project demonstrates an end-to-end data analytics workflow using **MySQL, Excel, Python, and Power BI**.

## Dataset

- 30 Customers
- 20 Products
- 150 Sales Transactions

### Tables

- **Customers** — customer details, demographics, location, and signup date
- **Products** — product name, category, brand, and unit price
- **Sales** — orders, quantities, discounts, payment modes, and order status

## SQL Analysis

Used SQL for:

- Revenue and order analysis
- Customer analysis
- Product performance
- JOINs
- GROUP BY and HAVING
- CASE statements
- Aggregate functions
- ORDER BY and LIMIT
- Filtering and business analysis

## Power BI Dashboard

The dashboard includes:

- Total Revenue
- Total Orders
- Active Customers
- Average Order Value
- Monthly Revenue Trend
- Top Products by Revenue
- Revenue by Brand
- Customer Analysis
- Decomposition Tree
- Interactive slicers
